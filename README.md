# ⛳️ ScoreRec PWA (GitHub Pages用)

ScoreRec を iPhone や Android のホーム画面でネイティブアプリ同様に全画面起動（アドレスバー非表示・アプリアイコン付き）させるための軽量ラッパーです。

## 🔒 プライバシー・セキュリティについて
- このフォルダ内のファイルには、**個人情報・スコアデータ・スプレッドシートデータ・APIキー等は一切含まれていません**。
- GitHub Pages で公開しても、機密データが外部に漏れることはありません。
- アプリのデータ通信は、利用者の端末（ブラウザ）と各自の Google Apps Script の間でのみ直接行われます。

## 📱 ファイル一覧
- `index.html`: 全画面 PWA ラッパー（スプラッシュ画面、URL設定、申し送りボード切替付き）
- `manifest.json`: Web App マニフェスト（アプリアイコン・テーマカラー設定）
- `icon-192.png`: アプリアイコン (192x192)
- `icon-512.png`: アプリアイコン (512x512)
- `icon.png`: 高解像度アイコン原画
